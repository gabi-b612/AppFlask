# 📊 Projet de Recommandation des films

Une application web de recommandation utilisant Flask, Pandas et scikit-learn pour calculer des similarités entre items.

## 🛠 Prérequis

- Python 3.10+
- pip (inclus avec Python)
- Git 

## 🚀 Installation

### 1. Cloner le dépôt (si applicable)
```bash
git clone https://github.com/gabi-b612/AppFlask.git
cd Projet2/AppFlask
```
### 2. Créer un environnement virtuel
```bash
python -m venv venv
```
### 3. Activer l'environnement virtuel
- Sur Windows :
```bash
venv\Scripts\activate
```
- Sur macOS/Linux :
```bash
source venv/bin/activate
```
### 4. Installer les dépendances
```bash
pip install -r requirements.txt
```
### 5. Lancer l'application
```bash
python app.py
```
### 6. Accéder à l'application
Ouvrez votre navigateur et allez à l'adresse suivante :
````
localhost:5000
````
